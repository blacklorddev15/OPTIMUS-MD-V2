# 𝗩𝗔𝗥𝗡𝗢𝗫 𝗫 𝗨𝗟𝗧𝗥𝗔 v2.0.5

  > WhatsApp Multi-Device Bot with Telegram Pairing Interface

  **Dev:** @Varnox_Or_novark  
  **Version:** 2.0.5

  ## Features
  - Pair WhatsApp accounts via Telegram bot
  - 100+ WhatsApp commands (games, GFX, downloads, group management, AI)
  - Multi-session support (up to 70 bots)
  - Railway/Cloud ready (no password prompt in production)

  ## Setup
  1. Clone this repo
  2. Copy `.env.example` to `.env` and fill in your values
  3. Run `npm install`
  4. Run `npm start`

  ## Environment Variables
  See `.env.example` for all required variables.

  ## Deploy to Railway
  [![Deploy on Railway](https://railway.app/button.svg)](https://railway.app)

  Set `BOT_TOKEN` and other env vars in Railway dashboard.
